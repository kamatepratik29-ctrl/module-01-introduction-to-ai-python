# Module 01 – Beginner-Friendly Python Programs

This repository contains five beginner-friendly Python programs for the
"Introduction to AI & Python" module.

## Programs

1. `01_add_two_numbers.py` – takes two numbers and prints their sum.
2. `02_even_or_odd.py` – uses the modulus operator and an if/else statement
   to check whether a number is even or odd.
3. `03_largest_of_three.py` – uses if/elif/else to find the largest of three
   numbers.
4. `04_factorial.py` – uses a for loop to calculate the factorial of a
   non-negative integer. The factorial of 0 is 1.
5. `05_sum_of_list.py` – uses a for loop to add all numbers in a list.

## Requirements

- Python 3

## How to run

Open a terminal in this folder and run one file at a time:

```bash
python 01_add_two_numbers.py
python 02_even_or_odd.py
python 03_largest_of_three.py
python 04_factorial.py
python 05_sum_of_list.py
```

On some Windows installations, use `py` instead of `python`.

## Concepts practised

- Input and output (`input`, `print`)
- Variables and numeric data types (`int`, `float`)
- Arithmetic operators (`+`, `*`, `%`)
- Conditional statements (`if`, `elif`, `else`)
- Loops (`for`, `range`)
- Lists

## Learning note

Read each program, run it, try different inputs, and explain the logic in
your own words. These examples are for beginner practice.
